## ☂️ 1. Design Patterns in Javascript

* ✅Teach:
     * Module Pattern (IIFE)
     * Revealing Module Pattern
     * Factory Function Pattern
     * Observer Pattern (basic pub-sub)

* ⚠️Confusion:
     
     * Module vs Factory
     * IIFE vs arrow function

* 🧠MindSet
     * Pattern are reusable ways to solve frequent design problems


* ✏️Practise:
      * Build Notification Service using Observer pattern
